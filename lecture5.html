Lecture 5: CSS Fundamentals, Selectors & Cascade

Syntax, Implementation, Combinators, Specificity & Typography

Summary

This lecture explores Cascading Style Sheets (CSS), the definitive standard for separating document presentation from structural markup. Students investigate CSS rule syntax, implementation methodologies (inline, internal, and external stylesheets), and diverse selector types—ranging from simple class and ID selectors to advanced combinators (child, sibling) and universal resets. The lecture thoroughly unpacks interactive pseudo-classes, generated content via pseudo-elements, the exact mathematical algorithm of Cascade Specificity, property inheritance, and comprehensive typography and color modeling (HEX, RGB, RGBA).

Topics Covered:

  • CSS Fundamentals & Implementation Methods
    • Presentation vs. Content: Decoupling design aesthetics from HTML semantics
    • Rule Anatomy: Selector, declaration block, CSS properties, and values
    • Three Inclusion Ways: Inline styles (style=""), Internal (<style> in head), and External stylesheets (<link rel="stylesheet">)
  • CSS Selectors & Combinators
    • Basic Selectors: Type/Element, Class (.btn), ID (#main), and Attribute selectors ([type="email"])
    • Grouping & Universal: Grouping selectors (h1, h2, h3) and Universal reset selector (*)
    • Combinator Selectors: Descendant (div p), Child / direct descendant (div > p), Adjacent sibling (h2 + p), and General sibling (h2 ~ p)
  • Pseudo-classes & Pseudo-elements
    • Interactive Pseudo-classes: :hover, :focus, :active, :visited, and :disabled
    • Structural Pseudo-classes: :first-child, :last-child, :nth-child(even|odd|An+B), :first-of-type, and :only-of-type
    • Pseudo-elements: ::before, ::after (with content property), ::first-letter, ::first-line, ::selection, and ::marker
  • The Cascade, Specificity & Inheritance
    • The Cascade Order: Importance (!important) > Specificity > Source order (last rule wins)
    • Specificity Weight: Inline (1,0,0,0) > ID (0,1,0,0) > Class/Attribute/Pseudo-class (0,0,1,0) > Element/Pseudo-element (0,0,0,1)
    • Inheritance: Inherited properties (color, font-family) vs. non-inherited (margins, borders), and control keywords (inherit, initial, unset, revert)
  • Typography & Visual Styling
    • Color Formats: Named colors, HEX (#0f766e), RGB (rgb(15, 118, 110)), and RGBA with alpha transparency channel
    • Font Stacks & Families: Serif, Sans-Serif, Monospace, generic fallback stacks, font-size, font-weight, and font-style
    • Text & Background Properties: text-align, text-decoration, text-transform, line-height, letter-spacing, and background shorthand

Example Code:

<!-- CSS Rule, Specificity & Pseudo-classes -->
<style>
  /* Class Selector with Interactive Pseudo-Class */
  .badge-demo {
    background-color: #0f766e;
    color: #ffffff;
    padding: 8px 16px;
    border-radius: 20px;
    font-size: 13.5px;
    font-weight: 600;
    display: inline-block;
    cursor: pointer;
  }
  .badge-demo:hover {
    background-color: #115e59;
  }
</style>

<span class="badge-demo">Hover Me: Specificity (0,0,1,0)</span>
