Lecture 8: Visual Styling, Motion, Web Fonts & Media Queries

Gradients, Shadows, Keyframe Animations, CSS Variables & Responsive Queries

Summary

This lecture delivers advanced styling techniques for contemporary front-end design. It unpacks modern visual effects including multi-stop linear/radial gradients, elevation shadows, border-radius geometry (pills and circular avatars), and color opacity versus alpha transparency channels. Students master fluid user interactions using 2D/3D hardware-accelerated transforms, transitions, and @keyframes animations, balanced with accessibility considerations (prefers-reduced-motion). Finally, the lecture covers typography embedding with @font-face, system tokens via CSS Custom Properties, and responsive multi-device design utilizing Media Queries (@media) and Feature Queries (@supports).

Topics Covered:

  • Visual Effects (Corners, Gradients, Shadows & Opacity)
    • border-radius: Rounded cards, circular profile avatars (50%), pill-shaped buttons (999px), and 4-corner clockwise syntax
    • Linear & Radial Gradients: Directional angles (45deg, 90deg, 180deg), color stops, radial spreads, and contrast overlay tints on hero images
    • Box Shadows (box-shadow): Multi-layer card elevation (x-offset, y-offset, blur-radius, spread, color) and inset shadows
    • Transparency: element opacity (affects parent and child contents) vs. rgba()/hsla() (applies alpha exclusively to targeted property)
  • Transforms, Transitions & Keyframe Animations
    • 2D & 3D Transforms: translate(), rotate(), scale(), skew(), 3D depth with perspective, and transform-style: preserve-3d
    • CSS Transitions: transition-property, duration, timing functions (ease, ease-in-out, cubic-bezier), delay, and shorthand
    • @keyframes Animations: Multi-step keyframes (0% to 100%), animation-name, duration, iteration-count (infinite), and direction (alternate)
    • Accessibility: Honoring user motion preferences using @media (prefers-reduced-motion: reduce)
  • Web Fonts, Icon Fonts & CSS Variables
    • Web Fonts & @font-face: Loading custom typefaces, modern web font formats (WOFF2, WOFF), font weights, and fallback stacks
    • Icon Fonts: Scalable vector glyphs and accessibility tagging (aria-hidden="true", aria-label)
    • CSS Custom Properties (Variables): --variable-name syntax, var() retrieval, :root global tokens, component scope, and live inheritance
  • Responsive Design & Browser Compatibility
    • Media Queries (@media): Breakpoint anatomy, fluid device width conditions (min-width, max-width), and orientation (portrait/landscape)
    • Feature Queries (@supports): Progressive enhancement testing for browser CSS capability support
    • Compatibility & Deployment: Historical vendor prefixes (-webkit-, -moz-, -ms-), autoprefixers, and deployment testing checklist

Example Code:

<!-- CSS Variables, Gradient, Transition & Hover Transform -->
<style>
  :root {
    --primary-teal: #0f766e;
    --accent-teal: #0d9488;
    --radius-pill: 999px;
  }
  .gradient-btn {
    background: linear-gradient(135deg, var(--primary-teal), var(--accent-teal));
    color: #ffffff;
    padding: 10px 22px;
    border-radius: var(--radius-pill);
    box-shadow: 0 4px 12px rgba(15, 118, 110, 0.3);
    border: none;
    cursor: pointer;
    transition: transform 0.25s ease, box-shadow 0.25s ease;
  }
  .gradient-btn:hover {
    transform: translateY(-2px) scale(1.03);
    box-shadow: 0 6px 16px rgba(15, 118, 110, 0.4);
  }
</style>

<button class="gradient-btn">Interactive Motion Button</button>
