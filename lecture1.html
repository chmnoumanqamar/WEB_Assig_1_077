Lecture 1: Introduction to Web & Internet Fundamentals

Course Foundation, Internet vs. WWW, Lifecycle, Tools & Web Standards

Summary

This lecture establishes the academic foundation for modern web engineering. It covers the course scope, prerequisites, grading criteria, and Course Learning Outcomes (CLOs). The lecture explores the fundamental architectural difference between the Internet (the global network infrastructure) and the World Wide Web (the information service operating on top of it). Students examine key platform components, development tools, authoring environments, the request-response lifecycle of the Client-Server model, and the crucial web standards bodies that govern open web technologies.

Topics Covered:

  • Course Foundation & Syllabus Overview
    • Course Scope & Prerequisites: Foundational knowledge in computing and basic programming
    • CLOs (Course Learning Outcomes): Front-end proficiency, client-side technologies, and web application design
    • Assessment & Grading: Assignments, lab evaluations, project deliverables, and examinations
  • Internet vs. World Wide Web (WWW)
    • Internet: Global interconnected network of hardware, routers, backbones, and communication protocols (TCP/IP)
    • World Wide Web: An information space of interlinked hypertext documents accessed via the Internet using HTTP
    • Working Concept: Data transmission, packet switching, and hypermedia delivery
  • Web Platforms & Key Components
    • Infrastructure: Data centers, cloud servers, CDNs, and network backbones
    • Development & Management: Content Management Systems (CMS), web APIs, and security practices
    • User Interface (UI): Front-end presentation layers and responsive cross-device interfaces
  • Website Lifecycle & Development Tools
    • Text Editors & IDEs: Plain text editors vs. feature-rich IDEs (VS Code, syntax highlighting, IntelliSense)
    • Authoring Tools: WYSIWYG builders vs. raw code authoring
    • Deployment & Hosting: File transfer protocols (FTP, SFTP, WinSCP), domain hosting, and modern browsers
  • Client–Server Model & Web Standards
    • Request-Response Lifecycle: User agent requests, DNS resolution, server processing, and HTTP responses
    • Governing Organizations: W3C (World Wide Web Consortium), WHATWG, ECMA (JavaScript standards), and IETF

<!-- Basic Web Document Skeleton -->
