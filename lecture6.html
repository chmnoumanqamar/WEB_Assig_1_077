Lecture 6: CSS Box Model, Display & Styling

Box Model Layers, Box-Sizing, Collapsing Margins, Dimensions & Display

Summary

This lecture delivers an in-depth examination of the CSS Box Model, which dictates how every HTML element is sized, spaced, and rendered by browser layout engines. It analyzes the four concentric layers: Content, Padding, Border, and Margin, alongside the directional TRBL (Top-Right-Bottom-Left) shorthand notation. Students explore the critical difference between the default content-box and modern border-box sizing paradigms, margin collapsing phenomena and their mitigations, overflow constraints, display property behaviors (block, inline, inline-block, none vs. visibility), curved borders, drop shadows, and consistent spacing architectures powered by CSS custom properties.

Topics Covered:

  • CSS Box Model Layers & Notation
    • Concentric Layers: Content area, Padding (internal clearance), Border, and Margin (external spacing)
    • TRBL Clockwise Rules: Shorthand properties accepting 1, 2, 3, or 4 values (Top, Right, Bottom, Left)
  • Box-Sizing Paradigm & Layout Calculation
    • content-box (W3C Default): Width and height apply only to content; padding and border add to the total rendered dimensions
    • border-box (Modern Standard): Total width and height include padding and borders, eliminating unpredictable layout wrapping
  • Margin Collapsing & Prevention
    • Collapsing Mechanics: Vertical margins of adjacent sibling block elements combine into a single margin equal to the largest value
    • Parent-Child Collapsing: Margins escaping unpadded containers
    • Prevention Techniques: Adding internal padding, border boundaries, or clearfix/overflow styling
  • Dimensions, Constraints & Overflow
    • Dimension Controls: width, height, min-width, max-width, min-height, and max-height for fluid responsive bounds
    • Overflow Management: Handling overflowing content via overflow: visible, hidden, scroll, and auto
  • Display Property & Box Visual Styling
    • Display Modes: block (breaks line, accepts dimensions), inline (flows within text, ignores vertical dimensions), inline-block (flows horizontally but respects full box model)
    • Hiding Elements: display: none (removes element from document flow) vs. visibility: hidden (invisible but preserves allocated geometry)
    • Visual Refinement: border styling, border-radius (curved corners, circular avatars), and multi-layer box-shadow
    • Spacing Systems: CSS custom properties (variables) like --spacing-sm, --spacing-md for scalable design systems

Example Code:

<!-- CSS Box Model with border-box and Box-Shadow -->
<div style="box-sizing: border-box; 
            width: 100%; 
            padding: 16px 20px; 
            margin: 10px 0; 
            border: 2px solid #0f766e; 
            border-radius: 8px; 
            background-color: #f0fdfa; 
            box-shadow: 0 4px 12px rgba(15, 118, 110, 0.12);">
    <strong style="color: #0f766e;">Box Model Component</strong>
    <p style="margin-top: 6px;">Content + 16px Padding + 2px Border + 10px Margin.</p>
</div>
