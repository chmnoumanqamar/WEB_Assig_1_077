Lecture 3: HTML & HTML5 Fundamentals & Content

Document Skeleton, DOM Tree, Text Formatting, Media & Semantic Tables

Summary

This lecture introduces the core structural foundation of web pages using HyperText Markup Language (HTML). Students master standard document skeletons, DOCTYPE declarations, and the hierarchical Document Object Model (DOM) tree. The lecture breaks down syntactic rules, void versus container tags, nesting requirements, and strict W3C validation. Furthermore, it comprehensively details core content elements—headings, rich text formatting, relative/absolute hyperlinks, media embedding (images, audio, video), list structures, and semantic data tables utilizing row and column spans.

Topics Covered:

  • HTML Fundamentals & Document Structure
    • Markup Role: Giving semantic meaning, structure, and hierarchy to raw text
    • Document Skeleton: <!DOCTYPE html>, <html>, <head> (metadata, charset, viewport, title), and <body>
    • DOM Tree Representation: Nodes, element nesting, parent-child-sibling node hierarchy
  • Syntax, Conventions & Validation
    • Elements vs. Tags vs. Attributes: Opening tag, attribute name-value pairs, element content, and closing tag
    • Void vs. Container Elements: Container tags (<p>,<div>) vs. self-closing void elements (<img>,<br>,<hr>,<input>)
    • Nesting & Standards: Proper nesting order and W3C HTML markup validation standards
  • Core Content & Formatting Elements
    • Headings & Paragraphs: Semantic heading scale (<h1> through <h6>) and text blocks (<p>)
    • Text Formatting: <strong> (importance), <em> (emphasis), <mark> (highlight), <del> (deleted), <ins> (inserted), <br>, and <hr>
    • Hyperlinks (<a>): Absolute URLs, relative paths, target attributes (_blank), and fragment identifiers (#id)
  • Lists & Multimedia Elements
    • Lists: Ordered lists (<ol>), unordered bulleted lists (<ul>), and description lists (<dl>, <dt>, <dd>)
    • Multimedia: Accessible images (<img> with required alt text), native audio playback (<audio controls>), and embedded video (<video controls>)
  • Tables & Semantic Tabular Data
    • Table Tags: <table>, table rows (<tr>), table headers (<th>), table data cells (<td>)
    • Semantic Sections: <caption>, <thead>, <tbody>, and <tfoot>
    • Cell Merging: Horizontal span (colspan) and vertical span (rowspan)
    • Page Flow Notice: Distinguishing block vs. inline elements, and why table layouts are obsolete for page skeletons

Example Code:

<!-- Semantic Data Table with Colspan -->
<table border="1" cellpadding="8" style="border-collapse: collapse;">
    <caption>Student Grade Record</caption>
    <thead>
        <tr>
            <th>Student Name</th>
            <th>Course Code</th>
            <th>Grade</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Muhammad Nouman</td>
            <td>CSC336 Web Tech</td>
            <td><strong>A</strong></td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="2"><em>Status:</em></td>
            <td><mark>Active</mark></td>
        </tr>
    </tfoot>
</table>

Output:

Student Grade Record
Student Name Course Code Grade
Muhammad Nouman CSC336 Web Tech A
Status: Active
