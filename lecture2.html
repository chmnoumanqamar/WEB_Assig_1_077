Lecture 2: Web Architecture, Protocols & Evolution

URL Anatomy, DNS, HTTP/HTTPS, Web App Types & Multi-Tier Systems

Summary

This lecture delves into the operational backbone of web communication and structural system design. It analyzes the precise syntax of Uniform Resource Identifiers (URIs and URLs), domain name resolution via DNS, and the mechanics of HTTP and secure HTTPS protocols. The lecture also traces the historical milestones of HTML from Tim Berners-Lee through the Browser Wars to HTML5, compares different application models (Static, Dynamic, MPA, SPA, PWA), and thoroughly evaluates multi-tier enterprise web architectures alongside their operational trade-offs.

Topics Covered:

  • Core Web Terminology & URI/URL Structure
    • URI vs. URL vs. URN: Identification vs. location-based resolution
    • URL Anatomy: Scheme (https://), Subdomain (www.), Domain name, Port (:443), Path (/courses), Query string (?id=101&sort=asc), and Fragment (#summary)
  • DNS Resolution & IP Addressing
    • DNS (Domain Name System): Hierarchical resolution translating human-friendly names to numerical IPv4/IPv6 addresses
    • DNS Lookup Lifecycle: Recursive resolvers, Root servers, TLD servers, and Authoritative nameservers
  • HTTP vs. HTTPS Protocols & Communication
    • Security: Cleartext HTTP vs. TLS/SSL-encrypted HTTPS
    • HTTP Request Methods: GET (retrieve), POST (create), PUT (replace), PATCH (modify), DELETE (remove)
    • Status Codes: 1xx (Informational), 2xx (Success, e.g. 200 OK), 3xx (Redirection, 301/302), 4xx (Client Error, 400/404), 5xx (Server Error, 500/503)
    • HTTP Headers: Content-Type, Authorization, User-Agent, Cache-Control, and Cookies
  • History & Evolution of HTML
    • Origin: Tim Berners-Lee at CERN (1989) and initial HTML proposals
    • Standards & The Browser Wars: W3C formation, HTML4 release, and browser fragmentation
    • The XHTML Era vs. WHATWG: XHTML strict XML rules vs. the WHATWG split driving real-world web needs
    • HTML5 Standardization: Modern semantic web, rich multimedia, and the Living Standard model
  • Web Application Paradigms
    • Static vs. Dynamic: Pre-rendered static assets vs. server-side database-rendered pages
    • Modern App Models: Multi-Page Applications (MPA), Single-Page Applications (SPA), and Progressive Web Applications (PWA)
  • Web Architectures & Tiers
    • Tiers vs. Layers: Physical hardware distribution (Tiers) vs. logical software separation (Layers)
    • Architectural Patterns: One-Tier (all on one host), Two-Tier (Client-Database), and Three-Tier / N-Tier (Presentation, Business Logic, Data Storage)
    • Trade-Offs: Scalability, fault tolerance, maintenance complexity, and infrastructure cost
